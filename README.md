# 남상엽 — Backend Portfolio

구글 문서 포트폴리오를 HTML로 옮긴 정적 페이지입니다. 빌드 없이 `index.html`만으로 동작합니다.

## 구조 — 웹 20쪽 = PDF 12쪽

- 1 표지+소개 → 2 Projects 목차(대표 이미지 자리 포함)
- House Of Ong R: 개요 → 문제 → 시나리오·원인 → 해결·구현 → 검증 → 효과·회고
- Chaerok: 개요 → 문제 → 해결(아이디어+대응 시나리오) → 구현 → 검증 → 효과·회고
- MatchUP: 개요 → 문제 → 측정·원인 → 해결·구현 → 검증 → 효과·회고
- 웹은 210×148.4mm 고정비율 9쪽 스냅, 세로 쌓기 레이아웃만 사용
- 인쇄는 흐름 배치: @page 10mm + 용지 패딩 상하 8mm·좌우 6mm(대화창 설정 무관), h2(프로젝트명) 앞에서 새 쪽 시작

## 웹 전용 기능

- 한 화면씩 스크롤 스냅 (`scroll-padding-top`으로 헤더 아래 안착)
- 스크롤 리빌 애니메이션 (떠나면 리셋, 돌아오면 리플레이)
- 핵심 구현 ①②③ 탭 인터랙션 (인쇄 시 3개 모두 출력)
- 내용 넘침 자동 축소 (`.fit` zoom, 861px 이상에서만)

## 로컬 확인

```bash
python3 -m http.server 8000
# http://localhost:8000
```

## PDF 내보내기

1. 우상단 `PDF로 내보내기` 클릭
2. Chrome 인쇄 설정:
   - 대상: PDF로 저장
   - 용지: A4, 여백: 기본값
   - 배경 그래픽: ON
   - 머리글/바닥글: OFF
